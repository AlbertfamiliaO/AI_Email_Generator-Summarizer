# 🤖 AI Email Generator & Summarizer

An Artificial Intelligence project built with **Python**, the **Groq API**, and an LLM to generate and summarize emails.

## 🎯 Challenge

The project consists of:

1. Generate **20 random emails** using AI.
2. Create a function that receives the list of emails and generates a **one-line summary** for each email, clearly identifying its main purpose.
3. Save the results to a `.txt` file.

## 💻 Example

**Email:**

```text
Hello, I am writing to confirm that we received your support request.
Our technical team is already reviewing it.
```

**Result:**

```text
Email #1: Confirmation that a technical support request was received.
```
